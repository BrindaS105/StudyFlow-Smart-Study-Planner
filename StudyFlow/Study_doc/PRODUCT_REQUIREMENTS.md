# Product Requirements Document – StudyFlow

## 1. Product Overview
StudyFlow is a study-planning application designed to help students
manage academic tasks and monitor their progress.

## 2. Problem
Students may forget deadlines and struggle to prioritize multiple
academic responsibilities.

## 3. Product Goal
Provide a simple interface to create, organize and track study tasks.

## 4. Target Users
- College students
- School students
- Competitive examination candidates
- Independent learners

## 5. Functional Requirements
- Users can create tasks.
- Users can assign a subject.
- Users can set a due date.
- Users can choose task priority.
- Users can mark tasks complete.
- Users can delete tasks.
- Users can search and filter tasks.
- Users can view completion statistics.

## 6. Non-Functional Requirements
- Simple user interface
- Responsive layout
- Fast interaction
- Browser-based storage
- Easy navigation

## 7. Success Criteria
The prototype should allow a user to create, update, filter and delete
study tasks while displaying accurate progress statistics.
