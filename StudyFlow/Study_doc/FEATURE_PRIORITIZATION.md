# Feature Prioritization – StudyFlow

Features are prioritized using a simple impact and implementation
effort assessment.

| Feature | Priority | Reason |
|---|---|---|
| Add tasks | High | Core functionality |
| Due dates | High | Helps deadline management |
| Mark completed | High | Tracks progress |
| Task statistics | High | Provides progress visibility |
| Search tasks | Medium | Improves navigation |
| Subject filters | Medium | Helps organize work |
| Priority selection | Medium | Supports task planning |
| Cloud synchronization | Low for MVP | Requires backend |
| Notifications | Low for MVP | Requires additional functionality |

## MVP Scope
The first version focuses on creating, managing and tracking tasks.

## Future Scope
Cloud storage, reminders and calendar integration can be considered
after validating the usefulness of the basic product.
