# Product Roadmap – StudyFlow

## Phase 1: MVP
- Create study tasks
- Add subjects and due dates
- Set priority
- Mark tasks complete
- Delete tasks

## Phase 2: Usability Improvements
- Search tasks
- Filter by subject
- Filter by completion status
- Display progress statistics

## Phase 3: Future Enhancements
- User accounts
- Cloud database
- Notifications
- Calendar integration
- Weekly reports

## Product Direction
Start with a lightweight task-management experience and expand based
on user feedback and observed usage.
