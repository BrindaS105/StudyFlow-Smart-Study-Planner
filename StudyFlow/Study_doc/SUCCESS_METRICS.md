# Success Metrics – StudyFlow

The following metrics are proposed for evaluating the product.

| Metric | Definition |
|---|---|
| Tasks Created | Number of tasks added |
| Task Completion Rate | Completed tasks / Total tasks × 100 |
| Pending Tasks | Number of tasks not completed |
| Active Users | Users who use the application during a defined period |
| Task Creation Rate | Average tasks created per user |
| Return Usage | Users who return to use the application |

## Primary Success Metric
Task Completion Rate.

## Supporting Metrics
- Number of tasks created
- Number of completed tasks
- Number of pending tasks
- Repeat usage

## Measurement Note
These are proposed product metrics. The current prototype does not
collect real user analytics or track multiple users.
