# StudyFlow – Smart Study Planner

## Overview
StudyFlow is a student productivity web application that helps learners
organize study tasks, set due dates, assign priorities and monitor progress.

## Problem Statement
Students often manage assignments, revision and exam preparation using
different tools. StudyFlow provides a simple dashboard to organize these
activities in one place.

## Features
- Add study tasks
- Assign subjects and due dates
- Set Low, Medium or High priority
- Mark tasks as completed or pending
- Delete tasks
- Search tasks
- Filter by subject and status
- View task statistics and completion progress
- Save tasks in browser local storage

## Technology Stack
- HTML
- CSS
- JavaScript
- Browser Local Storage

## How to Run
1. Download or clone this repository.
2. Open the project folder.
3. Double-click index.html.
4. The application opens in your browser.

## Product Scope
This is a front-end prototype. Task information is stored locally in the
browser and is not synchronized across different devices.
